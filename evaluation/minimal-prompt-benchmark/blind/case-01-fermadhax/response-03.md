# Anonymous response 03

结论：暂不批准新增1,000吨/年 FermaDHA-X 中国成人 Omega-3 软糖专线；先用6周完成低成本验证，达标后再决策。

依据：

- 现有产能尚未证明不足：2025年混合发酵油名义产能2,000吨，实际生产900吨、销售720吨、库存260吨；缺少按品级和国家拆分，无法证明必须扩产。
- 需求不能直接转为销量：4万吨“油当量需求”不是采购需求；六份询盘合计2,600吨，但存在同集团重复、浓度与交期不一致，且均未完成技术认证或形成约束订单。
- 产品准入和可销售性未验证：缺少中国精确产品授权、配方稳定性、感官、货架期及客户认证证据。
- 价格不可比：现有报价在浓度、数量、税费、运费、账期和日期上未对齐，无法判断可执行售价和利润。
- 新线的认证收率、利用率、可售产量、库存政策及挤占其他产品的机会成本均未知。

下一步：在6周内完成①中国精确产品身份与法规路径书面审查；②向独立买方发出统一规格、数量、交期、Incoterms和付款条件的匹配RFQ；③完成40% DHA软糖的稳定性、感官和初步货架期测试；④将六份询盘去重并转化为经技术认可、含价格和年度数量的采购意向；⑤比较现有共享线可释放产能与新线的分阶段经济模型。只有在法规路径明确、产品通过客户资格验证、可执行需求足以支持合理利用率且贡献利润为正时，才进入专线投资审批。
