# Anonymous response 04

结论：现阶段不值得建设5,000吨/年产线。精确法律路径、犬用目标产品证据、猫用营养与安全证据以及可比经济性均未成立，应先做12周验证；猫完整粮不得据现有材料推进。

依据：

- PV9缺少消化率、残余核酸、霉菌毒素、批次差异和灭活验证。现有28天研究使用的是KCL-24而非PV9，且未覆盖猫、长期使用或完整蛋白替代。
- PV9内部犬粮试验只有挤压外观，没有对照、适口性、消化率、营养充分性、临床或货架期数据。
- 美国材料对应PV7人类食品，不覆盖PV9动物食品；中国也没有精确产品批准或法律意见。
- 七封非约束意向函存在同集团重复、犬零食与完整粮混杂、添加比例差异，且没有合格规格、价格、技术认证或绑定数量。
- 目标成本4.80美元/kg明显高于所列鸡副产物粉1.40美元/kg，但双方尚未按可消化氨基酸、运费、质量和合同条款统一比较。买方可接受溢价也以适口性、消化率和可辩护宣称为前提，且缺少成品添加量，无法证明贡献利润。

下一步：

1. 先取得中美PV9动物食品精确法律路径结论。
2. 完成批次规格、灭活、污染物及关键成分检测。
3. 开展受控犬粮研究，验证适口性、消化率、粪便、临床指标和目标添加量。
4. 猫粮另行补齐猫特异营养与饲喂证据后再评估。
5. 用统一功能性可消化蛋白口径完成报价和贡献经济性；任一管理层否决条件触发即停止建线。
