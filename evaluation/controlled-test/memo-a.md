# Anonymous memo A

**决策备忘录：FermaDHA-X 中国成人软糖产线**

**结论：进行有边界验证，暂不扩产。** 现有材料不足以计算可信供需缺口，也不足以支持新增1,000吨/年名义产能。

**已核实事实：** 2025年现有共享线名义产能2,000吨，混合油实际产量900吨、销量720吨、年末库存260吨；但无中国、40% DHA或软糖级分项。六项非约束询盘合计2,600吨，但存在同一采购集团重复、浓度与交期不一致，且均未完成技术认证或形成订单。现有中国品牌标签只能证明市场上有藻油DHA软糖，不能证明FermaDHA-X需求。

**估算：** 无法可靠估算供需缺口。现有线表面上有1,100吨名义闲置产能，但共享线约束、各品级分配和可售产出未知，不能视为可供40% DHA产品的供应量。40,000吨营养缺口不是采购需求；2,600吨询盘也不是可成交需求。全球鱼油缺口与本项目口径不匹配。

**假设：** 只有在40% DHA软糖级能够合规、通过配方与客户认证，并在可接受价格下形成足量采购时，新线才可能必要。

**未知：** 中国准入、稳定性/感官/货架期、认证收率与利用率、可售产量、同口径成交价格、客户真实年采购量及现有线机会成本。

**六周内最小改判证据：** 向去重后的买方发出统一规格、价格、贸易条款和交付期RFQ，同时完成精确产品准入审查与小试认证；若获得覆盖新增线最低经济可售产量的、通过技术资格且带价格的书面采购承诺，再进入扩产决策。
