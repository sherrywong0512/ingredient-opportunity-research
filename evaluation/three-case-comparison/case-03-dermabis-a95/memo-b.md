# Anonymous Memo B

## DermaBis-A95中国面部护肤专线决策备忘录

**建议：`run a bounded shared-line validation`，不批准当前1,800万美元、300吨/年的专线。**

**已核实事实**
DermaBis-A95为发酵来源、含量95%的α-红没药醇；立体异构体、杂质、气味和氧化规格及其与植物来源`(-)-α-红没药醇`的等同性均未明确。A95的直接技术证据仅包括：0.2%、三次重复的供应商表皮模型试验，以及0.1%–0.5%免洗乳霜专利实例；前者不是人体试验，后者只有初始外观。一个A95乳液样品仅在室温稳定四周。20人、14天人体结果使用的是0.5%植物来源材料，不能直接转移至A95。中国清单只列通用INCI名称`BISABOLOL`，不能证明A95确切身份适用、成品安全或抗炎功效宣称成立。

**格式与采用边界**
两家零售网站单日可见的12款标签只能证明通用红没药醇存在：8款免洗乳霜/乳液、4款洁面；不能识别A95、来源、浓度或因果效果。免洗乳霜/乳液可进入条件验证；透明水剂精华缺增溶证据、眼周缺耐受证据、洁面缺沉积证据，均不应外推。

**需求与经济性**
供应商称全球需求500–800吨/年但无方法；“20亿件×20%采用×0.2%用量”中的采用率和用量均无证据。四项非约束询盘共180吨/年，含集团重复、一个要求>99%植物来源、一个未说明剂型，且均未完成验证，因此A95需求及供需缺口无法可靠估算。专线70%利用率对应210吨，制造成本32美元/公斤；若按24美元/公斤目标价，制造环节即约亏168万美元/年。90%利用率对应270吨、成本25美元/公斤，仍约亏27万美元/年，且尚未计销售、法规和融资成本。现有价格因含量、来源、立体化学、日期、税运和条款不一致，不是可执行售价。

**最小变更证据**
用无新增专线资本的2吨共享线完成：A95确切身份及中国法规意见；以免洗乳霜/乳液为唯一首轮格式，做对照、稳定性、包装相容性和人体耐受验证；取得同规格、10吨批量、统一税运及付款条件的匹配RFQ。只有可执行售价高于专线完全成本、合格需求支持利用率且技术与法规均通过，才重启专线决策。
