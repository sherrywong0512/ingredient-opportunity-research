# Anonymous response 06

结论：现阶段不应新增1,000吨/年专线；先执行六周商业、合规和技术验证，再决定是否投资。

依据：

- 现有2,000吨混合发酵油产能在2025年仅生产900吨、销售720吨，且年末库存260吨。虽然无法确认40% DHA专用品类是否受现有产能约束，但当前材料没有证明必须新增产能。
- “4万吨需求”来自推荐摄入差额，不是采购需求；2030年鱼油缺口也不对应中国成人软糖、发酵油或40% DHA规格。
- 六项询盘合计2,600吨，但存在同一集团重复，浓度、交付时间和交易条件不一致，且均未完成技术认证或形成绑定订单。
- 价格观察口径不一致，无法证明可执行售价及专线利润。
- 缺少FermaDHA-X在中国的精确产品授权、软糖配方稳定性、感官、货架期和客户认证证据；良率、利用率及可售产量也未知。

下一步：

1. 在六周内完成中国精确产品与用途的法规档案审查。
2. 以40% DHA软糖级统一规格、数量、交付期和贸易条件发出RFQ，去除关联买方重复后确认可执行价格与真实需求。
3. 用现有共享线完成客户样品、配方稳定性、感官、货架期及技术认证。
4. 建立不同利用率下的完整单位经济模型，并核实共享线扩产机会成本。
5. 仅当认证需求超过共享线可供能力、价格覆盖完整成本且出现可执行采购承诺时，再提交新线投资决策。
