## 备忘

**结论：当前不值得建设面向中美犬猫完整粮的 5,000 吨/年专线**，属"法规未决 + 技术证据不足 + 经济性未验证"，管理层三条否决线均无可通过证据。

**依据（仅事实包）**
1. 身份与靶动物证据缺失：PV9 自身无饲喂研究；犬粮试验用的是 KCL-24 菌株（4% 与 8% 添加，8% 组第 1–4 天自愿采食量下降），未测 PV9、猫、生长、繁殖、过敏、长期与全量替代；无任何猫数据，猫完整粮的牛磺酸、精氨酸、含硫氨基酸、花生四烯酸、维生素 A 充足性均无数据；内部试验为 20% 替代鸡肉粉的无对照挤压试验。
2. 法规路径未决：GRAS 公告只覆盖 PV7 的美国人类食品，不含 PV9、动物饲料或完整宠物粮；无 FDA 动物饲料咨询、AAFCO 定义或州注册；中国饲料原料目录摘录中未见"PV9 真菌生物质"。管理层明示法规路径未决即否决。
3. 需求仅为意向级：7 封非约束性意向合计 9,000 吨/年，其中 3 家同属一个集团、2 封仅指狗零食、添加量 2%–20%，无规格、饲喂试验、价格或条款；无猫买家完成技术审查。全球宠物食品 1,400 亿美元仅有零售口径，无完整粮产量、蛋白体系占比或添加率。
4. 经济性未验证：目标成本 4.80 美元/kg（90% 利用率）与试产 7.20 美元/kg 均高于鸡肉粉挂牌 1.40 美元/kg（60% 粗蛋白），且无可消化氨基酸等价口径；唯一溢价信号 0.12 美元/100g 以适口性、消化率和可辩护宣称被证明为前提，且无配方用量。

**下一步（管理层可资助 12 周）**：①完成中美法规路径专项审查并确认 PV9 与 PV7 GRAS 的身份对应；②开展以 PV9 为受试物、含对照与统计的犬粮试验（适口性、消化率、粪便/血检、保质期）；③补猫完整粮必需营养素充足性评估；④按可消化蛋白等价口径重算贡献毛利并做匹配询价；⑤意向去重并锁定规格、用量与约束性承诺。全部通过后再议产线规模，不直接批 5,000 吨专线。
