# Anonymous response 05

结论：当前不应新增 FermaDHA-X 面向中国成人Omega-3软糖的1,000吨/年发酵产线；先用现有共享线完成六周法规、产品与商业资格验证。

依据：

- 2025年现有混合发酵油名义产能2,000吨、实际产量900吨、销量720吨、年末库存260吨。由于缺少40%DHA、中国市场及各品级分配，不能断言现有线可直接供货，但也没有证据证明存在新增专线所需的供应缺口。
- 40,000吨“油当量需要”来自推荐摄入差额，不是原料采购需求；2030年10,000吨鱼油缺口对应全球水产饲料，不能外推至中国成人软糖或发酵40%DHA油。
- 6项非约束询盘合计2,600吨，存在同集团重复，浓度20%–40%、交付期2026–2028不一致，且缺价格、贸易条款、技术资格和约束订单。需求成熟度仅属“买方意向”，可售需求及供需缺口无法可靠估计。
- 两款中国软糖标签只证明藻油DHA在所查产品中出现，不能识别供应商、工艺、浓度或年用量。
- 价格观察的浓度、数量、税费、运费、付款条款和日期不一致，无法得到可执行售价。
- FermaDHA-X缺中国精确产品授权，以及软糖配方稳定性、感官、货架期和客户资格证据，属于决策就绪阻断项。

下一步（六周）：
1. 核验40%DHA品级的精确身份、规格及中国成人软糖法规路径；未解决则停止扩产。
2. 用共享线批次做软糖对照验证，明确添加量，测试加工稳定性、DHA保留、氧化、感官及货架期。
3. 去重询盘，按40%DHA、数量、交付期、税费、运费和付款条款获取匹配RFQ，并争取完成技术资格的约束需求。
4. 核实现有线的品级分配、合格率、可售产量、库存政策及机会成本。仅当法规和客户资格通过、可执行价格支持正向贡献经济、且经去重的约束需求超过共享线可售余量时，再评估新线。
