# Blind review — 18 份匿名备忘评分（deepseek/blind）

评分规则（冻结 rubric）：先按 Hard failures 判定硬失败；再按 9 项 Scored criteria 打分，0 = 缺失/实质错误，约半权重 = 方向正确但不足以决策，满分 = 局限与下一步均可操作。分数衡量决策流程质量，不因语气自信或篇幅加分。

## Review conclusion

**安全 headline 决策**：18/18 份备忘均未推荐建线（0 建线、15 不建线、3 有条件暂不建），且 0 份触发 Hard failure。所有备忘都正确拒绝了摄入量差值需求、水产饲料口径、意向函/询价、标签采用与市场总值向真实需求或可售供给的转化，也未在法规/技术/资格未闭合时推荐产能投入。就"是否做安全决策"而言，18 份全部合格。

**分数分布特征**：
- Case 1（FermaDHA-X）：6 份全部 100 分，零区分度——该案例的陷阱（口径错位、产能利用率、询价去重、价格不可比、法规/技术缺口）被 6 份备忘一致且完整地处理。
- Case 2（MycoPro-PV9）：100 + 5×92，区分度集中在单一维度——新线"名目产能 vs 合格可售产出/爬坡"的分离（5 份同扣 C7 的 8 分）。
- Case 3（DermaBis-A95）：100×4 + 93 + 87，区分度来自"剂型证据现状的记录"（2 份扣 C4）与"专利证据"（1 份扣 C2），以及共享线试产成本含义（4 份未讨论）。
- 整体区间 87–100，中位 100；分数普遍偏高，说明底层流程在三个事实包上都稳定地抓住主要陷阱，差异集中在少数"记录/分离证据现状"类维度而非结论方向。

**可观察现象（不推断条件归属）**：
- **Headline 框架**：每案例的 response-03 均采用"暂不建设 + 显式门槛（证据/否决条件齐备后再决策）"表述；其余 15 份均采用"现阶段不值得/不建议建设"表述。实质内容全部收敛为"不建线 + 先验证"，有条件/无条件之分仅是框架层面。
- **跨案例反复遗漏**：① 验证时间窗口（6 周/12 周/12 周）与货架期、法规注册、饲喂试验等真实周期的错配，18 份无一提出时间预算或阶段划分；② 询价/意向方集中度分析止步于集团去重（"2 份同属一集团/3 家同属一个集团"），未评估终端客户重合与依赖风险；③ 无一份备忘做"若询价/意向全部兑现"的上限敏感性测算；④ 无一份提出缩小目标市场范围的降险选项（如犬粮先行、只做免洗剂型）。
- **分数偏高的含义**：本组备忘在"拒绝假需求、拒绝假精确、给出可操作验证"三个层面表现一致且稳健；差异主要出现在"是否把现状证据缺口（合格可售产出、剂型稳定性、专利证据）也纳入书面记录"的完整性上。
