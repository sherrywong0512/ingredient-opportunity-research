# Anonymous response 01

结论：当前不应建设 MycoPro-PV9 5,000 吨/年专线；仅推进“犬用完整粮验证”，猫用完整粮暂不推进。

依据：
- 身份与安全未闭环：PV9 缺氨基酸消化率、核酸、霉菌毒素、批间差异及灭活验证。现有犬试验对象是 KCL-24，不是 PV9；仅28天，8%添加早期采食量下降。
- 技术证据不足：PV9台架试验只有单一犬粮配方和外观结果，无对照、适口性、消化率、营养充足性、临床指标或货架期。猫粮所需关键营养数据及猫试验均缺失。
- 中美法规均未解决：PV7的人食GRAS不能外推至PV9动物完整粮；中国仅在不完整目录节选中未检出，不能据此判定允许或禁止。
- 需求不可作为扩产依据：7封非约束性意向合计9,000吨/年，但存在同集团重复、犬零食偏离目标范围、添加量不一致，且无规格、价格、技术审查或约束量。需求成熟度仅属“买方意向”，供应约束与缺口均无法可靠估计。
- 经济性未成立：目标成本4.80美元/kg依赖90%利用率；试产成本7.20美元/kg。鸡副产物粉虽为1.40美元/kg，但缺可消化氨基酸、物流和合同口径，不能直接比较。买方可接受成本也因PV9实际添加量未知而无法核算。

下一步（12周）：
1. 完成PV9在中美犬用完整粮的精确法规路径、规格和灭活/污染物审查；任一目标市场仍未解决即不建线。
2. 以鸡副产物粉体系为对照，做PV9犬粮受控试验，测适口性、采食、粪便、消化率、氨基酸充足性、临床指标及稳定性；持续异常即停止。
3. 获取同规格、同贸易条款RFQ，并按可消化蛋白功能等效基础核算添加量、成品成本和贡献经济。
4. 去重并重新资格审查买方，取得通过技术审查且含规格、价格和约束量的需求后，再用合格率、可售产量、爬坡利用率及营运资金重算专线；否则继续小试，不作资本承诺。
