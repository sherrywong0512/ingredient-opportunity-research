# Anonymous Memo A

**决策：run a bounded shared-line validation。暂不建设300吨/年专线，先聚焦有现有标签信号的留敷乳霜/乳液。**

**证据判断：**A95的精确身份尚不完整：缺少立体异构体、残留溶剂/杂质、气味、氧化及与植物来源`(-)-alpha-bisabolol`的等同性资料。现有A95技术证据仅为供应商赞助的三重复重建表皮试验、专利配方示例及一份室温四周乳液样品，不能证明人体效果、独立复现或商业货架期。20人研究使用的是植物来源成分，不能直接外推至A95。透明水精华、眼周、冲洗型及包装相容性均无适配证据。

中国清单出现通用`BISABOLOL`，但未解决A95生产路线、立体化学、杂质和规格是否属于既有使用身份，也不支持抗炎功效宣称。12个SKU只能证明通用成分的有限在售使用，不能证明供应商、路线、浓度或因果效果。

市场与经济性不支持专线：全球需求500–800吨/年缺少独立方法；180吨/年询盘不具约束力，存在同集团重复及规格不匹配。价格样本在纯度、立体化学和交易条件上不可比。专线70%利用率时成本32美元/kg，高于24美元/kg目标售价；90%时25美元/kg仍未含销售、监管和融资成本，且合格收率与售出率未验证。

**验证边界：**

1. 完成A95精确身份、规格及中国监管适用性的正式核验。
2. 用共享线生产2吨，验证合格收率、批次一致性，并针对留敷乳霜/乳液完成稳定性、耐受性和包装相容性工作。
3. 向独立买方取得同规格、同交易条件的匹配RFQ，并完成配方、安全及采购资格验证。
4. 以可执行售价重新核算含相关成本的经济性和可售规模。

只有精确身份与监管路径明确、格式验证通过，且可执行售价或已验证的平台价值足以覆盖成本时，才重审专线；否则不建设。
