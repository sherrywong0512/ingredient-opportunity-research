# Anonymous Memo B

**决策：run a bounded dog-food validation。暂不批准5,000吨/年产线，猫粮不进入本轮。**

**证据判断：**PV9的确证仅有65%粗蛋白和一次无对照的犬粮挤压台架测试，缺少消化率、氨基酸、核酸、霉菌毒素、批次差异及灭活验证。28天犬试验使用的是KCL-24而非PV9，只支持有限的菌株转移线索；8%添加早期采食下降，且未覆盖长期、全替代或猫。猫所需关键营养适配数据为空，不能从犬或其他菌株外推。美国GRAS涉及PV7人食，不覆盖PV9动物食品；中国目录摘录不完整，既不能证明准入，也不能证明禁止。

需求与经济性尚不足以支持专线：9,000吨意向均不具约束力，存在同集团重复、犬零食口径和2%–20%添加差异；没有合格规格、价格或确定销量。目标成本4.80美元/kg尚未实现，当前为7.20美元/kg；鸡副产物粉价格虽低，但缺少可比的可消化氨基酸、运费和合同口径。终端溢价也尚未与实际添加量连接。

**12周验证边界：**

1. 完成中美PV9精确产品、动物食品用途及完整犬粮场景的监管路径书面核验。
2. 固定目标犬粮配方和添加量，设置对照，验证采食、适口性、粪便、临床指标、蛋白及氨基酸消化表现，并补齐规格、批次和灭活证据。
3. 取得同口径买方规格、配方用量、可执行价格与数量，按功能等效的可消化蛋白口径核算贡献经济性。

若法律路径未解决、犬试验出现持续采食/粪便/临床问题，或等效口径贡献仍为负，则停止宠物食品项目；三项均通过后再审规模化，不将犬结果外推至猫。
