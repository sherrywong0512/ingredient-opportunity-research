# FermaDHA-X扩线决策备忘录

**建议：开展有边界验证（run a bounded validation），六周内不批准新增1,000吨/年产线。**

**已核实事实**
FermaDHA-X为发酵来源油，拟议中国成人软糖级含40% DHA。2025年共享产线名义产能2,000吨，混合油产量900吨、销量720吨、年末库存260吨，但无品级或国家分配。六项非约束询盘合计2,600吨，含同一采购集团，浓度为20%–40%、交期为2026–2028年，均未完成技术验证或形成订单。两款中国软糖只能证实标签含藻油DHA，不能证实本品采用或用量。

**估算与缺口判断**
仅可计算共享产线名义余量1,100吨、名义产能利用率45%；二者都不是40% DHA中国软糖级的可销售供给。4万吨摄入差额属于潜在终端需要，2030年鱼油缺口与本决策口径不符。需求成熟度为“买方意向（stated buyer interest）”，供应约束为“未解决（unresolved constraint）”，供需缺口为“无法可靠估算（not reliably estimable）”。

**假设与未知**
扩线成立须假设中国合规、软糖稳定性/感官/货架期、客户验证及经济性均通过。当前未知可销售产出、合格率、利用率、库存政策、共享产线机会成本和商业用量。现有价格在活性规格、数量、日期、税费、运费/Incoterms、付款条件及供应商类型上不一致，不能形成可执行价格或单位使用成本。

**最小变更证据**
形成一张同口径供需表：完成中国档案初审及一次客户小试后，取得去重买方对“40% DHA、中国成人软糖、明确年度量与交期、含税到货价、付款条件”的可转订单书面承诺，并与现有产线可分配的合格可售量比较。只有需求超过现有供给且贡献经济性可接受，才重启扩线。
