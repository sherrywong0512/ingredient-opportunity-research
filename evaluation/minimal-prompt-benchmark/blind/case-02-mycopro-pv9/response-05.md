# Anonymous response 05

结论：目前不值得建设面向中美犬猫完整粮的5,000吨/年专线；应先完成12周验证，再决定是否立项。

依据：

- 产品基础证据不足：PV9仅有65%粗蛋白数据，缺少氨基酸消化率、残余核酸、霉菌毒素、批次波动和灭活验证。
- 动物证据不可直接外推：28天犬试验使用的是KCL-24而非PV9，且未覆盖猫、长期使用和完整蛋白替代；PV9内部犬粮测试无对照、适口性、消化率及统计分析。猫粮所需关键营养数据和猫试验全部缺失。
- 中美合法路径均未确认：现有GRAS材料不是PV9，也不适用于动物完整粮；美国相关咨询、定义和注册缺失，中国也无确切准入证明。
- 需求质量弱：9,000吨意向均不具约束力，存在同集团重复、犬零食需求及2%–20%添加比例混杂，无已确认规格、价格或采购量，也无猫客户完成技术审核。
- 经济性尚不成立：目标成本4.80美元/kg依赖90%利用率，试产成本7.20美元/kg，而对比原料报价为1.40美元/kg；尚无按等效可消化蛋白口径的配方和贡献利润证明。5,000吨产能的合格率、爬坡、可售产量和营运资金均未知。

下一步：

1. 明确PV9在中美犬粮、猫粮中的具体准入路径及所需试验。
2. 先做受控PV9犬粮试验，验证适口性、粪便、消化率、临床指标和氨基酸充分性；猫粮另立验证，不以犬数据替代。
3. 将意向转为同一规格、添加比例、价格和年度量的客户技术审核与条件订单。
4. 按等效可消化蛋白计算配方成本和贡献利润，并验证利用率爬坡。
5. 若法律路径未解决、目标动物出现持续摄食/粪便/临床问题，或贡献利润仍为负，则停止专线项目。
